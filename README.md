
# Neopixel Demo
Began 2026-04-28
* This is an initial proof-of-concept demo for a neopixel on RPi4 only.
* This version requires the neopixel to be wired to GPIO18 (physical pin 12).
* This version requires explicit sudo privileges and different wiring.
<br>See LLM_chats/ for more info

* Look for the next repo for a plain user version.
